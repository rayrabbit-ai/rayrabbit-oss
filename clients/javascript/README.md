# RayRabbit Client SDK for JavaScript / TypeScript

> **Status:** 🚧 **Active Development (Roadmap v0.2.0)**  
> **Target Runtimes:** Node.js 20+, Bun, Deno & Modern Browsers  
> **License:** Apache-2.0

## Overview
This directory hosts the upcoming official JavaScript / TypeScript Client SDK and A2UI React renderers for the **RayRabbit Universal Interoperability Infrastructure (L3)**.

### Planned Architecture & Features
* **`@rayrabbit/client`**: Sovereign Agent Node SDK with persistent WebSocket (`ws://:8005/ws`), automatic Zod-to-JSON Schema conversion and dynamic MCP tool registration.
* **`@rayrabbit/a2ui`**: Reactive Server-Driven UI component catalog for Next.js, React 19, and Lit Web Components.
* **Protocol Parity**: Zero-Trust JWS signature verification (Web Crypto API) and Google A2A JSON-RPC 2.0 client.

---
*For current stable implementations and sovereign node creation, please refer to the Python SDK in [`clients/python/`](../python/) and the root [`README.md`](../../README.md).*

# SDK Cliente de RayRabbit para JavaScript / TypeScript

> **Runtimes Objetivo:** Node.js 20+, Bun, Deno y Navegadores Modernos

## Visión General
Este directorio alojará el SDK oficial de JavaScript / TypeScript y los renderizadores React A2UI para la **Infraestructura de Interoperabilidad Universal RayRabbit (L3)**.

### Arquitectura y Capacidades Planificadas
* **`@rayrabbit/client`**: SDK para Nodos Agentes Soberanos con conexión persistente WebSocket (`ws://:8005/ws`), conversión automática de esquemas Zod a JSON Schema y registro dinámico de herramientas MCP.
* **`@rayrabbit/a2ui`**: Catálogo de componentes reactivos Server-Driven UI para Next.js, React 19 y Lit Web Components.
* **Paridad de Protocolos**: Verificación criptográfica de firmas JWS Zero-Trust (Web Crypto API) y cliente nativo Google A2A JSON-RPC 2.0.
